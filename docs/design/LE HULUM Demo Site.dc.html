LE HULUM adds Ethiopian Sign Language, captions, audio description and a low-data mode to any video or text lesson, in Amharic and English. Add it to your site with one script tag.

How to install

Add the script once, then use <db-player> wherever you show a lesson. It follows your page’s light or dark theme.

<script type="module" src="https://cdn.lehulum.org/db-player.js"></script>

<db-player src="lesson.mp4" lang="am" sign="auto"></db-player>

What is a variable?

A variable is a name that holds a value. Think of it as a box with a label on it. In Python, you make a variable by writing a name, an equals sign and a value.

name = "Abebe"

This line stores the text “Abebe” in a variable called name. To see the value, use print:

print(name)

Python shows Abebe on the screen.
