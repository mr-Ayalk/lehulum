# LE HULUM (ለሁሉም)

Ear to the deaf. Eye for the blind.

LE HULUM is a plug-in for a lesson page, not a separate app. One script tag gives a Deaf learner Ethiopian Sign Language, a blind learner a document they can skim, and a learner on a slow connection a small version of the same lesson. A small server prepares those tracks. The phone does not run the AI.

## Run it

```bash
docker compose up --build
```

Then open:

- http://localhost:8080/demo/blank.html
- http://localhost:8080/pages/concept-with-navigation.html
- http://localhost:8080/api/v1/health
